# Personal Portfolio — Awa Mbaye

My personal portfolio website showcasing my background, technical skills, research experience, and projects in **Artificial Intelligence, Data Science, Software Development, and Applied Mathematics**.

🌐 **Live Website:** [awambaye.com](https://awambaye.com/)

## Tech Stack

- **Next.js** — React framework
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Responsive styling
- **React** — Reusable UI components

## Features

- Modern, responsive, minimalist design
- Bilingual support (English and French)
- Dedicated project pages with images and technical details
- Research experience and educational background
- Downloadable resume
- GitHub and LinkedIn integration

## Getting Started

Clone the repository and install the dependencies:

```bash
git clone https://github.com/BrokerRecord/BrokerRecord.dev.git
cd BrokerRecord.dev
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
